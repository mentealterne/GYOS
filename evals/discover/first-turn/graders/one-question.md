The final message is the opening of an interview, not a finished model.

PASS only if all of these hold:
- It asks the user exactly one question (a single question, possibly with a few proposed answers to choose from). Several unrelated questions in a list is a FAIL.
- The question is about purpose and strategy (who pays, why customers choose it, what is bought off the shelf, tenancy) or asks for a concrete past story, as a first discovery question should.
- If it proposes an answer, the proposal is labelled as strong, inferred or speculative (or clearly marked as an assumption to confirm).
- It does not present a complete list of bounded contexts or a glossary as settled facts.
